# Fraunces font source

Fraunces is the official Google Fonts variable old-style serif used by the Hopi Hari interface. The canonical specimen is available at <https://fonts.google.com/specimen/Fraunces>. The source repository is <https://github.com/undercasetype/Fraunces>, which includes distributable font files and the SIL Open Font License 1.1 in `OFL.txt`.

For the weekly PDF, the preferred implementation is an embedded distributable TTF from the official repository. If runtime loading fails, the renderer must fall back to a standard serif face without blocking the report export.
